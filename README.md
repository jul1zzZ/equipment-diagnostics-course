# Диагностика оборудования — учебный тренажёр

Интерактивный курс по вибрации, диагностике неисправностей и контролю состояния промышленного оборудования.

Внутри:

- 17 учебных модулей;
- понятные объяснения без лишней воды;
- тесты и сохранение прогресса в браузере;
- диагностический тренажёр;
- инженерные калькуляторы;
- словарь терминов.

Сайт работает как статическое приложение и публикуется через GitHub Pages.
